# Music Atlas 提示词插槽

这些 Markdown 文件是可编辑的提示词空间。程序按固定顺序读取它们并附加到 Step 3 Agent prompt 中。

Step 2 分析 Agent 使用 `analysis_agent.py` 中的独立研究协议，不加载这些候选插槽。它逐批接收本次快照，输出带 scope、confidence、逐项证据的画像和音乐人关系；程序校验后才聚合为 Step 3 的分析包。分析研究 prompt 和 manifest 在本次 `analysis_research/` 中，不能手工修改后继续执行。

提示词只能补充分析标准、风格边界与候选研究要求。最终说明由程序依据已选曲目生成，修改文案插槽不会直接改写最终推荐文本。提示词不能改变：

- Step 1 本次快照的歌曲数量
- Step 2 的确定性频率与风格计数
- 当前输入与历史运行的隔离边界
- 推荐去重、艺人/项目上限和证据契约
- 覆盖率门槛、程序拥有的关系判定、评分与推荐说明

研究时优先覆盖本次 `interest_profiles`，不要把多个兴趣压成总体均值。补充轮遵守 `research_request` 的缺额、剩余预算和排重标识，不重复要求首轮全量候选。修改插槽后需要重新 `prepare-agent`；已准备上下文不会自动刷新。
